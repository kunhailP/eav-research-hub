## 코딩 설계 (CrowdFlower)
- **문장 사전 선택이 없다.** 선언문 전체를 썼다(논문 각주 4). 앞뒤 2문장을 맥락으로 보여 주었다. HIT당 10(또는 5)문장이다.
- **1라운드(모든 문장), 선택 문항:** "이민 및/또는 이민자 통합과 관련 있는가?" 응답은 예=1, 아니오=0, 불확실=0.5다. **평균이 0.5 이상이면 1이다.** 코더는 3명 이상이다(234,415문장이 정확히 3명). CrowdFlower level 3 코더만 참여했다. 결과는 selection=1이 8,965문장(3.81%)이다.
- **2라운드(1라운드에서 선택된 문장만):** 주제 문항은 이민=1, 통합=2이고 **최빈값**으로 집계한다. 방향 문항은 지지=1, 중립=0, 회의=−1이고 **중앙값**으로 집계한다. 코더는 5명 이상이고 level 2–3이다. 결과는 이민 3,899, 통합 5,066이다. 방향은 지지 5,740, 회의 2,252, 중립 973이다.
- **품질 관리:** 입장 퀴즈(1R 5문장, 2R 10문장)를 두었다. 작업 중에 gold 문장(전문가 합의 정답)을 섞었다. trust score 미달 코더는 제외하고 코딩을 다시 수집했다. gold는 1R 748문장, 2R 278문장이고 코딩 수가 많다(최대 203, 84).
- **합의도** `certainty_*`는 최빈 응답의 비율(%)과 정확히 맞는다. agreement × n / 100이 모든 행에서 정수다.
- **개별 코더 응답과 코더 id는 공개되지 않는다.** 집계 라벨, 코더 수, 합의도만 있다. 선택 문항은 3범주에 평균 규칙을 쓰므로 범주별 분포를 복원할 수 없다. 방향 문항도 3범주에 중앙값 규칙을 쓰므로 복원할 수 없다.
- 저자가 수동 코딩한 문장이 221개다. 크라우드 코퍼스에서 빠진 190개와 아일랜드 '이민 아닌 이주(emigration)' 재코딩 31개다.

## 알려진 한계
1. **조건부 표본:** 주제와 방향은 크라우드 3명이 선택한 문장에만 있다. 1라운드 위음성은 방향 라벨을 영영 받지 못한다. LLM의 방향 비교는 인간 선택에 조건부가 된다.
2. **크라우드 품질:** 1라운드는 코더 3명이다. 지시문 번역은 독일어·스페인어뿐이고 나머지 언어는 국가 제한과 언어 요건으로 대신했다(10개 언어). 방향 문항은 합의 100%가 43.5%에 그친다.
3. **범위:** 중동유럽이 없다. 1998–2013이다. 캐나다는 1회, 미국은 정당 2개다. 뉴질랜드는 선택 비율이 0.4%다.
4. **자료 결함:** `61620_200811`(미국 공화당 2008)은 2,014행이 모두 위치 1156–2308에 두 번씩 들어 있다. 앞부분 1–1155가 없다. 쌍 17개는 selection이 서로 다르다. 공개 party 파일의 saliency도 이 중복을 포함한다. `pos_corpus`가 없는 235문장(핀란드 국민연합 2007, 독일 녹색당 2013)은 텍스트를 `mis_verbatim.csv`에서 가져온다.
5. **코퍼스 버전 의존:** 위치 병합은 2015-3 기준이다. 다른 버전에서는 위치가 달라질 수 있다.
6. CMP 601/602/607/608 범주는 크라우드 선택 문장의 약 42%만 포괄한다(논문). 두 기준을 같은 구성개념으로 취급하면 안 된다.

## v3 설계(docs/12_red_team.md §C3) 대응
| C3 항목 | PImPo로 가능한 것 | 제약 |
|---|---|---|
| 1차 기준 자료(같은 단위·같은 질문·다평정자) | 준문장 단위로 선택→주제→방향의 원래 과제를 재현한다 | 다평정자 정보가 **집계 수준**뿐이다 |
| 다평정자 잠재모형 / DIF | topic은 범주별 수가 정확해 이항 모형이 가능하다. 선택·방향은 (n, 라벨, 최빈 비율)만으로 부분 가능도를 쓴다 | 코더 id가 없어 평정자별 효과와 **인간 1인 대비 비교**는 직접 불가하다. 최빈 비율로 무작위 인간 1인의 일치 확률만 근사한다 |
| 잡음 기준선(인간 반분) | 불가하다. 대신 합의도 분포와 gold 정답 대비 정확도를 쓴다 | 반분에는 개별 응답이 필요하다. Benoit 2016 UK로 보완한다 |
| 실질 추정량(정당가족 × 연도 이민 위치) | 선언문 242개와 MPDS parfam으로 공개 immi_pos·inti_pos를 그대로 재현한다 | 선거 38개, 1998–2013 |
| 선거 단위 분할 | `election_id`(국가_날짜) 38개로 분할한다 | 국가당 1–4회라 보류 집합이 작다 |
| 과제 동일성 | LLM에도 1R 3응답(불확실 포함, 평균 규칙)과 2R 주제·방향을 같게 준다 | 2R은 인간 선택 문장에서만 비교한다. 전체 문장 방향은 별도로 추정한다 |

재현: `python data_prep/pimpo.py --src data/raw/pimpo --dest data/pimpo --mpds <MPDS csv>`. 텍스트는 `MANIFESTO_API_KEY=... python data_prep/manifesto_texts.py --items data/pimpo/items.csv --cache data/raw/manifesto_api --dest data/pimpo`로 붙인다.

## 갱신 (2026-09-14): API 접근 확보
- **API 키:** 사용자 키를 `/root/.config/manifesto/api_key`(권한 600)에만 저장한다. 저장소·로그·문서에는 기록하지 않는다. 스크립트는 `MANIFESTO_API_KEY="$(cat ~/.config/manifesto/api_key)"`로 넘기고, 키는 POST 본문으로만 보낸다.
- **텍스트 수집 검증:** 선언문 2개(585 quasi-sentence)로 실제 API를 시험했다. 코퍼스 버전 20150708174629에서 위치 매칭 100%, 원문과 CMP 코드를 함께 받았다. 전체 242개 수집은 `results/pimpo_text_fetch.log`.
- **정당가족 공식 확인:** 공식 MPDS2024a를 `get_core`로 받았다(`data/raw/mpds/MPDS2024a_api.csv`, 5,151개 선언문). PImPo 242/242 매칭, 앞서 쓴 GitHub 사본과 parfam 불일치 **0건**. 분포: 생태 28 · 사회주의 27 · 사민 38 · 자유 35 · 기민 28 · 보수 29 · **민족주의/급진우파 23** · 농민 10 · 민족/지역 16 · 특수 8.
- **버전 규칙:** ADR-0009(gold ≤ 2024a)에 따라 PImPo 분석의 정당가족은 **MPDS2024a 공식본**으로 고정한다. 코퍼스 2015-3 버전에는 영어 번역이 없다. 원문 vs 번역 비교에는 번역이 있는 이후 버전과 위치 재매칭이 필요하다(별도 사전등록).
- **전체 텍스트 수집 완료 (2026-09-14 06:08):** 242/242 선언문 위치 매칭 100%. quasi-sentence 235,353개 전부 텍스트 확보(코퍼스 235,118 + mis_verbatim 235), CMP 코드 누락 0. 파일 `data/pimpo/items_text.csv.gz`(재배포 금지, gitignored).
