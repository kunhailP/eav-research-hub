## 1. 논문의 질문

**Can We Compare Parties Measured by Language Models?**

LLM 측정은 이제 비교정치의 표준 도구가 되어 가고 있다 (Benoit et al., AJPS). 검증은 주로 인간 코딩이나 전문가 조사와의 **상관**, 또는 **정확도·F1**으로 한다. 그런데 정치학의 주장은 대부분 **비교**다: 정당가족 간, 국가 간, 시기 간 비교다. 비교가 타당하려면 측정오류가 집단 간에 같아야(측정 불변) 한다. **현재의 검증 방식은 이 조건을 시험하지 않는다.**

핵심 예시 (계산 확인됨): 정당가족별로 LLM 측정이 −0.25 SD 이동하면 인간 코딩과의 상관은 **r = 0.987**로 유지된다. 그런데도 참 격차 +0.21 SD가 **−0.04 SD**로 뒤집힌다.

## 3a. 재현 대상 검증 결과 (2026-09-14) — 설계 변경 (ADR-0007)

**결정적 제약: 문장 단위 텍스트가 없는 선언문이 대부분이다.** Abou-Chadi & Krause (2020) 재현 자료(Dataverse KYSD5S, 426행)를 MPDS2024a와 맞춰 보았다(`data_prep/coverage_check.py`). 결과는 다음과 같다.
- 현재 선언문에 코퍼스 텍스트가 있는 비율은 38.4%다.
- first difference에 필요한 **현재와 직전 선언문이 모두 있는 비율은 21.8%**다.
- 시기별로는 1975–1990년 0%, 1991–2000년 2%, 2001–2008년 21%, **2009–2015년 83%**다.
- 따라서 **발표된 추정치를 LLM 재코딩으로 재현하는 설계는 불가능하다.** 텍스트가 있는 부분표본에서 결론이 달라져도 표본 차이 때문인지 측정 차이 때문인지 분리할 수 없다.

**변경된 설계: "같은 분석 사양, 같은 표본, 코딩만 교체".** 발표 논문의 분석 사양(변수 구성, 모형)을 사전등록으로 고정한다. 그다음 **텍스트가 있는 시기(주로 2009년 이후)에서 인간 CMP 코드로 한 번, 각 LLM 코드로 한 번** 추정한다. 비교 기준은 발표된 숫자가 아니라 **같은 표본의 인간 코딩 결론**이다. 이 시기에는 코드북 5판의 이민 하위범주(601_2, 608_2)도 쓸 수 있다.

## 3e. 최신 자료의 정치학적 의미와 제약 (2026-09-14 조사, ADR-0009)

**정치학적으로 의미가 있는 이유**
1. **측정 선택이 결론을 가를 수 있는 바로 그 시기다.** 2015년 이민 충격 이후 2023–26년 급진우파 약진기(예: 독일 2025)가 이어졌다. MPDS2025a는 Fidesz·PiS·Brothers of Italy를 정당가족 70(민족주의·급진우파)으로 **재분류**했다. 데이터 버전만 바뀌어도 "급진우파" 표본이 바뀐다.
2. **도구에 따라 결론이 갈린다는 증거가 이미 나왔다.** Gessler & Hutter (2026, Party Politics)는 PolDem과 Manifesto를 비교했다. 위치는 수렴하지만 **주목도는 틈새정당·비경제 이슈에서 도구마다 다르다.**
3. **기계 코딩 결론은 이미 최상위 학술지에 실린다.** Werner & Habersack (2025, BJPolS)은 XLM-RoBERTa로 코딩한 선언문으로 17개국 1946–2022 결론을 냈다. Benoit & Laver (2026, WEP)는 LLM으로 22개 언어 주목도를 쟀다. "기계로 잰 정당을 비교해도 되는가"는 가정의 질문이 아니라 **현재 관행에 대한 질문**이다.
4. **빈틈:** 2023–26년 최상위 학술지에서 **동·서유럽 전염 효과를 직접 비교 검정한 연구는 발견되지 않았다.** Minkenberg의 "서유럽은 급진우파를 길들이고 동유럽은 주류가 급진화한다" 논지가 미검증 상태다. 이 논문의 사례 A가 이 빈틈과 겹친다.

**제약**

**추가 후보 대상 D (확인 필요):** Werner & Habersack (2025, BJPolS)의 **기계 코딩 기반 발표 결론**을 같은 문서의 인간 CMP 코드로 다시 추정한다. C4의 역방향이고, "최상위 학술지에 실린 기계 측정 결론이 인간 측정에서도 유지되는가"에 답한다. 재현 자료 공개 여부를 먼저 확인한다.

| LD − Lab 1997 우파 비중 | −0.162 [−0.241, −0.078] | +0.035 [−0.033, 0.110] | **결론 반대** ("자민당이 노동당보다 좌" vs 차이 없음) |
| Con − Lab 격차 추세 (10년당) | −0.083 | −0.146 | 방향은 같고 크기가 다름 |

**함의:** 검증된 인간 도구 두 개가 선언문 수준에서 r = .96으로 일치하면서도 핵심 비교 결론이 달라진다. P6 사각지대가 기계에만 국한되지 않는다는 실제 사례이며, 논문 서론의 첫 사례 후보다. 논문에 쓰기 전에 원 스크립트의 집계 방식으로 재계산한다.

**자료 무결성 메모:** Ornstein, Blasingame & Truscott (2024) 재현 자료의 `application3-benoit-manifesto-estimates.csv`("Benoit et al. 2016에서 전사")는 우리 원코딩 재구성과의 상관이 r = 0.952다. **1992와 1997 라벨을 맞바꾸면 r = 0.989로 오른다.** 원 R 스크립트의 선언문 ID 순서가 1987, 1997, 1992…이므로, 전사 과정에서 연도 라벨이 뒤바뀌었을 가능성이 높다. 이 파일을 벤치마크로 쓰지 않고, 원 논문의 표·그림과 대조하기 전까지는 결론을 인용하지 않는다.

## 3c. 추가 설계: 정당 단서 조작 실험 (메커니즘 식별)

같은 문장을 두 조건으로 라벨링한다: **(i) 문장만 제시 (ii) "다음은 [정당명]의 선언문 문장이다"를 덧붙여 제시.** 두 조건의 라벨 차이를 정당별로 비교하면 정당 단서가 만드는 차등 오류를 **인과적으로** 식별할 수 있다. 문장은 동일하므로 텍스트 차이로 설명되지 않는다. 비용은 모델당 코퍼스 1회 추가뿐이다. 실제 연구 워크플로는 선언문 단위로 입력해 정당을 알 수 있는 경우가 많으므로 조건 (ii)가 현실적인 사용 조건이다. 따라서 이 실험은 "현실 사용 조건에서 결론이 바뀌는가"를 직접 검정한다.

## 4. 2주 kill test (본 투자 전)

**단계 순서 (단독 수행 기준):** ① 영어·정당가족: Benoit 2016 UK로 수행하며 지금 바로 가능하다 → ② 정당 단서 조작 (3c) → ③ 언어 간 비교: Manifesto API 키 확보 후.

Case A(언어 간 차등 오류)가 실제로 존재하는지 가장 싸게 확인한다.

- **표본:** 4개 언어(예: 영어, 독일어, 폴란드어, 헝가리어 `[확인: CMP 코딩 선언문 존재]`) × 언어당 약 400 quasi-sentence. 대상 범주를 과대표집한다.
- **모델:** 3개 (강한 API 1, 중형 open-weight 1, 소형 open-weight 1). 프롬프트는 고정한다.
- **추가 조작:** 원문 vs CMP 제공 영어 번역본. 번역이 언어 격차를 없애는지 본다. 없앤다면 그 자체가 해법 후보다.
- **측정:** 언어별 FPR/FNR, 대상 범주 비중의 언어별 이동을 선언문 간 분포의 SD 단위로 표시한다.
- **판정**
  - **GO:** 적어도 한 모델에서 언어별 이동 ≥ 0.25 SD, 또는 언어 간 FNR 차이 ≥ 10pp.
  - **Case A 폐기:** 모든 모델에서 |이동| < 0.10 SD. 이 경우 Case B(정당가족)로 같은 검사를 반복한다.
  - **둘 다 폐기:** AJPS 경로를 접고 PA 방법론 논문에 집중한다.

## 5. 필요 자원

| 항목 | 규모 | 비고 |
|---|---|---|
| LLM 코딩 | 재현 3편의 국가·기간에 해당하는 quasi-sentence × 6–8 모델 | 실행 전 토큰 수로 비용을 추산한다. open-weight가 주분석 |
| 전문가 재코딩 | 2,000–4,000 문장, 코더 2–3명 | 결론이 갈리는 층에 집중한다. **"누가 맞나"에 답하는 유일한 수단** |
| 공저자 | **선택 사항** | 아래 "단독 수행 계획"으로 대체할 수 있다 |
| Manifesto Project 문의 | 파생 라벨 공개 허가 | 재현 패키지 |

### 단독 수행 계획 (공저자 없이)

공저자가 해 줄 일은 세 가지다. 각각을 혼자 할 수 있는 방법으로 바꾼다.

| 공저자가 주는 것 | 단독 대체 |
|---|---|
| 재현 대상 선정의 신뢰성 | **기계적 선정 규칙**: 예) 2010년 이후 AJPS/APSR/BJPolS/CPS에서 CMP 주목도 변수를 쓴 논문 중 인용 상위 N편. 규칙을 사전등록한다 |
| "누가 맞나"를 가를 human 재코딩 인력 | ① **기존 다중 코딩 자료**: Benoit et al. (2016, APSR) UK 선언문 문장의 전문가·크라우드 코딩(Baumann repo의 manifestos task 원자료) `[확인]`, CMP 코더 신뢰도 시험 자료(Mikhaylov et al. 2012) `[확인]` ② 영어권 사례는 본인이 blind 프로토콜로 코딩하고, 유급 코더 1명과 부분 교차 코딩 ③ 외국어 사례는 CMP 원어민 코드를 gold로 쓰고 "누가 맞나" 판정은 하지 않는다 |
| 비교정치 해석 검토 | 원 논문 저자에게 재현 결과를 보내 의견 요청, PolMeth/EPSA 발표, arXiv 선공개 피드백 |

**단독 수행 시 범위 조정:** 영어권 정당가족 사례(UK·아일랜드·호주·뉴질랜드·캐나다·미국)를 주 사례로 한다. 본인이 직접 문장을 읽고 오류를 검토할 수 있기 때문이다. 언어 간 비교는 CMP 원어민 코드 대비 차등 오류만 보고한다. 재현 대상은 3편(대조군 포함)을 유지한다.
**고유 자산:** CMP에 한국 정당 선언문이 있다면 `[확인]` 본인이 원어로 오류를 판정할 수 있는 비영어 사례가 된다.

## 6. 이 경로가 실패하는 방식

1. 실제 LLM의 차등 오류가 작아서 아무것도 흔들리지 않는다. → kill test가 2주 안에 잡는다. 이 경우 "조건 X에서는 안전하다"는 결과로 PA에 낸다.
2. 흔들리지만 사전 예측이 틀린다. → 이론의 설명력이 약하다는 뜻이다. 기술적 논문으로 격하한다.
3. 전문가 재코딩 결과 LLM이 인간 코더보다 맞다. → 흥미로운 반전이다. "CMP 인간 코딩의 차등 오류" 논문으로 전환한다.
4. 같은 질문을 비교정치 LLM 연구 그룹이 먼저 낸다. → 주간 arXiv 모니터링. kill test가 GO이면 arXiv 선공개를 앞당긴다.
