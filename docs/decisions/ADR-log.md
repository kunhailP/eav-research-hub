## ADR-0001 · 문제를 "두 regime의 estimand-aware 선택"으로 재정의 (2026-09-14)
- **결정:** 원 질문("최고 F1 = 최고 estimand?")을 plug-in과 correction 두 regime의 선택 기준 문제로 재구성한다.
- **맥락:** 원 질문은 Baumann 2025(경험적), Bross 1954(불변 오분류), MoE-PPI/MultiPPI 2026(분산)과 부분적으로 겹친다.
- **근거:** 02_theory P0, P4. 01_positioning §3.
- **되돌리는 조건:** 파일럿에서 correction regime 이득이 전무하면 plug-in 단일 regime 논문으로 축소한다.

## ADR-0002 · 파일럿 1차 통계량은 상대 regret, argmin 일치율은 2차 (2026-09-14)
- **결정:** P(m_F = m_θ)를 GO/KILL 기준에서 제외한다.
- **근거:** S3에서 δ=0.1만으로 세 대비의 최적 모델 일치율이 1.00→0.16으로 떨어졌다. 비슷한 품질의 모델 사이 argmin은 잡음에 지배된다.

## ADR-0003 · 파일럿에서 프롬프트 고정, open-weight 주분석 (2026-09-14)
- **결정:** task당 프롬프트 1개, temperature 0. open-weight 모델이 주분석, API 모델은 보조.
- **근거:** 프롬프트 변이는 Baumann의 주제이므로 모델 선택 효과만 분리한다. 재현성(R8, K7)도 확보한다.

## ADR-0004 · Debiased EAV-plugin (B̂² − V̂) 사용 중단 (2026-09-14)
- **결정:** 기본 plug-in 기준을 `eav_structural`로 한다. `eav_plugin`은 CSV에만 기록한다.
- **근거:** S2에서 불편추정 B̂²−V̂는 V̂가 큰 모델을 선호했다. δ=0, n=400에서 초과오차가 2.92pp로 BA(0.17pp)의 17배였다.
- **되돌리는 조건:** 실제 자료에서 structural이 체계적으로 열등하면 재검토한다.

## ADR-0005 · 기준선 비교 대상은 F1이 아니라 balanced accuracy (2026-09-14)
- **결정:** 모든 표·그림에 BA 선택을 포함하고, 핵심 대결 구도를 "EAV vs BA"로 설정한다.
- **근거:** P1. S1에서 δ=0일 때 BA가 편향 최적 모델을 100% 선택했다. F1만 이기는 결과는 심사에서 R1 공격에 무너진다.

## ADR-0006 · AJPS 실질 논문을 flagship 후보로 추가, 2주 kill test로 결정 (2026-09-14)
- **결정:** "Can We Compare Parties Measured by Language Models?"를 정치학 질문으로 시작하는 AJPS 논문으로 설계한다 (09_ajps_substantive_design). 이론 중 P0·P3와 상관 사각지대만 이 논문에 넣고, P4와 EAV 성능 비교는 PA 방법론 논문으로 분리한다.
- **맥락:** PA 경로의 최대 약점은 "정치학 결론이 실제로 바뀐 사례"가 없다는 점이다 (R11).
- **근거:** 상관 r=0.987에서도 격차 부호가 뒤집히는 계산 예시. 현재 LLM 비교 측정의 검증 관행이 상관·F1 중심이다.
- **되돌리는 조건:** 언어·정당가족 kill test에서 모든 모델의 집단별 이동이 0.10 SD 미만이면 AJPS 경로를 접는다.

## ADR-0007 · "발표 추정치 재현"에서 "같은 사양·같은 표본·코딩 교체"로 전환 (2026-09-14)
- **결정:** 비교 기준을 발표된 숫자가 아니라 텍스트가 있는 시기(주로 2009년 이후)의 **인간 CMP 코딩 결론**으로 한다. 분석 사양은 Abou-Chadi & Krause (2020)과 Abou-Chadi (2016)에서 가져와 사전등록한다.
- **맥락:** Abou-Chadi & Krause 표본 중 first difference에 필요한 두 선언문의 텍스트가 모두 있는 비율은 21.8%이고, 2000년 이전은 거의 0%다 (`data_prep/coverage_check.py`).
- **근거:** 부분표본에서 발표 결론과 달라지면 표본 효과와 측정 효과가 섞인다. 같은 표본 안에서 코딩만 바꾸면 측정 효과만 식별된다.
- **대가:** "유명 결과가 뒤집혔다"는 서사는 쓸 수 없다. 대신 "같은 질문을 오늘 LLM으로 연구하면 결론이 달라지는가"에 답한다. 이 질문이 현재 연구자에게 더 직접적이다.
- **한국 사례:** 코퍼스 텍스트가 2020년 5개 선언문뿐이라 주 사례에서 제외한다.

## ADR-0008 · 인간 기준선(H6) 추가 · gold와 추정량 구성 규칙 사전 고정 (2026-09-14)
- **결정:** (1) 1차 gold는 전문가 다수결, 2차는 크라우드로 한다. (2) 같은 코더가 같은 문장을 두 번 코딩하면 **마지막 코딩**을 쓰고, 전체 평균은 민감도 분석으로 돌린다. (3) 선언문 점수 구성(문장 평균 방향 / 우파 문장 비중)은 킬테스트 사전등록에 명시한다. (4) 가설 **H6 (인간 기준선)** 을 추가한다: LLM–전문가 비교 결론의 차이를 **크라우드–전문가 차이**와 같은 척도로 비교한다.
- **맥락:** Benoit 2016 원코딩을 재구성해 보니 크라우드와 전문가의 선언문 수준 경제 위치 상관은 **r = 0.962** (18개 선언문)였다. 그런데도 New Labour 이동(1992→97)은 평균 위치 기준 전문가 **+0.53**, 크라우드 **+0.21**이었다. 우파 문장 비중 기준으로는 +0.33 vs +0.09로 CI가 겹치지 않는다. 1997년 자민당–노동당 격차는 전문가 −0.16(유의), 크라우드 +0.04(CI가 0 포함)였다. 두 추정량 구성에서 같은 패턴이 나왔다.
- **근거:** P6의 사각지대가 **검증된 인간 측정도구 사이에서도** 실제로 나타난다. LLM만의 문제가 아니라 비교 측정 일반의 문제로 논문을 쓸 수 있고, "크라우드만큼은 비교 가능한가"라는 실용적 기준을 준다.
- **주의:** 이 수치는 원 논문의 척도화 방식이 아니라 우리 재구성(최신 코딩, 문장 평균)에 기반한다. 논문에 쓰기 전에 원 스크립트의 "means of means" 방식(`06 Produce Paper Tables and Figures/manuscript_analysis.R`)으로 다시 계산한다.

## ADR-0009 · gold 시점 규칙 · 분석 창 2015–2022 · API 모델 포함 · C5는 확장으로 격하 (2026-09-14)
- **결정:**
  1. CMP 인간 gold는 manifestoberta 공개(2024년 1월) **이전 릴리스에 이미 있던 코드**를 1차로 한다. 이후 추가분은 표시하고 보조 분석에만 쓴다.
  2. 전염·동서 비교의 주 분석 창은 2015–2022년이다.
  3. API 모델(Claude Opus 5 · Sonnet 5 · Haiku 4.5)을 로컬 open-weight 4종과 함께 측정도구로 포함한다. 거부 시 폴백은 끈다.
  4. 정당 단서 조작(C5)은 Vallejo Vera & Driggers (2025)의 **확장**으로만 제시한다.
  5. 오염은 로컬 모델의 cutoff 전후 비교와 OLMo-2 학습 데이터 점검으로 다룬다.
- **맥락:** 최신 자료 조사와 차별점 스캔 결과 (09 §3e, 01 §3b).
- **되돌리는 조건:** Manifesto Project가 최근 릴리스에 기계 보조가 없었다고 확인하면 1번 제약을 푼다.

## ADR-0010 · 다공급사 모델 · 대상 E(Benoit et al. 2026 자료 재분석) 우선 · 삼중 도구 틀 (2026-09-14)
- **결정:**
  1. Anthropic 외에 OpenAI·Google 프런티어 모델도 측정도구로 포함한다. 키가 확보되면 라벨러에 백엔드를 추가한다.
  2. Benoit et al. (2026) 재현 자료로 **사전등록 재분석(대상 E)**을 킬테스트 ①과 병행해 가장 먼저 실행한다.
  3. 논문은 반박이 아니라 **삼중 도구(LLM · 전문가 조사 · CMP) 동등성** 틀로 쓴다. gold를 가정하지 않는 비교 결론 일치를 1차 결과로 한다.
  4. 앙상블 명제 P7(공유 편향은 평균으로 사라지지 않음)을 이론에 추가한다.
- **맥락:** 차별점 스캔에서 Benoit et al.이 가장 가까운 논문으로 확인됐다. 재현 자료로 선언문 235개, 선언문×이슈 1,307칸, 급진우파 27·녹색 24 선언문의 검정이 가능하다 (docs/11 §3.2).
- **절차 규칙:** 대상 E의 대비 목록을 고정하기 전에는 집단별 잔차를 계산하지 않는다. 2026-09-14에는 표본 크기만 확인했다.

## ADR-0011 · Red team 결과에 따른 v3 설계 전환 (2026-09-14)
- **결정:** docs/12 §C3 표 전체를 채택한다. 핵심은 네 가지다. ① 1차 기준 자료를 PImPo + Benoit 2016 UK(같은 단위·같은 구성개념·다평정자)로 바꾼다. ② 1차 통계량을 다평정자 잠재모형 DIF로, 판정을 TOST 3분류 + max-T 순열 + 인간 잡음 기준선으로 바꾼다. ③ 동서 비교와 C3(audit 예측)를 AJPS 논문에서 제외한다. ④ P6·P7을 기여에서 격하한다.
- **대체하는 것:** ADR-0008의 인간 사각지대 해석, 킬테스트 ① v1·v2 판정 규칙(docs/10), 대상 E의 DIF 해석(docs/11 §3.2), 원고 초록과 H1–H6.
- **맥락:** 자체 점검(v1 규칙 귀무 거짓 GO 100%, C6 감쇠)과 독립 검토자 3인(비교정치, 방법론, Benoit et al. 입장)의 치명 결함 지적.
- **절차:** v3 사전등록 전에 인간 크라우드 라벨과 모의 불변 라벨로 전체 파이프라인을 돌려 **거짓 GO ≤ 5%**를 확인한다. 이 확인이 끝나기 전에는 어떤 LLM 라벨도 생성하지 않는다.
