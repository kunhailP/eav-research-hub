# 13 · v3 사전등록 초안 — LLM 코더의 집단 조건부 측정 동등성

> 상태: **LOCKED 2026-09-14** (`docs/decisions/LOCKS.md`의 `prereg-v3-uk`). 이하 본문은 LOCK 시점 그대로다. ADR-0011. LOCK 조건: (1) 모의 귀무 거짓 비동등 ≤ 5% — **경제 영역 충족(0/25, D17)**, **사회 영역 충족(0/25, D19)**; (2) PImPo 자료 구조 확정 — **충족**(docs/data_cards/pimpo.md; PImPo는 이 사전등록의 UK 확증 분석에 포함하지 않고 별도 사전등록); (3) 아래 `[LOCK 전]` 항목 채움. LOCK은 이 파일의 sha256과 UTC 시각을 `docs/decisions/LOCKS.md`에 기록하는 것으로 한다.
> **알고 설계한 것(공개 의무):** Benoit et al. (2026) 가림 자료의 정당가족별 요약, 결측률의 정당가족별 차이, UK 전문가–크라우드 선언문 수준 관계(기울기 0.62). 이 외의 LLM 라벨은 아무것도 보지 않았다.

## 1. 질문과 추정량
- **질문:** LLM 코더가 같은 텍스트 단위에 같은 코딩 과제를 수행할 때, 정당(가족)에 따라 오류가 인간 코더보다 더 다른가. 그렇다면 정당 집단 평균 점유율이 얼마나 왜곡되는가.
- **1차 추정량:** `delta_pp[g]` (docs/12 §D13). 잠재 참값은 **인간 코더만으로** 정의한다. LLM의 집단별 오류율이 만드는 집단 평균 점유율 왜곡을, 집단 간 통합(불변) 오류율이 만들 왜곡과 비교하고 기준 집단(Lab)과 대비한 값. **단위: pp. SESOI: 3pp**(확정).
- **인간 기준선:** 같은 통계량을 인간 코더 각각에 leave-one-out으로 계산해 나란히 보고한다. 빼지 않는다.
- **2차:** 집단 간 민감도·위양성률 차이 (`sens_diff`, `fpr_diff`), 별도 계열로 max-T 보정.

## 3. 측정도구
- **과제:** 원 코더와 같은 3영역 × 5점 선택(11개 선택지, 제약 디코딩), 앞뒤 문장 맥락. 영역이 목표 영역이면 1로 이진화해 잠재모형에 넣는다.
- **프롬프트 변형:** `label/tasks/v3/uk_area_position_{a,b,c}.json`. 변형은 무작위 요인이며 판정 규칙(§4)에서 재현 조건으로 쓴다.
- **모델:** 로컬 open-weight 4개(아래 적격성 적용 결과, `v3/run_uk.py` MODELS에 전체 revision 고정). API 모델(Anthropic·OpenAI·Google)은 키 확보 후 같은 사전등록으로 추가한다.
- **정당 단서 조건:** 1차 분석에서 제외. 별도 기제 분석으로만.
- **선택지 순서:** 문장마다 결정적으로 무작위화한다(`shuffle_choices`, seed = 과제명 + sentence_id).
- **모델 적격성 (인간 코드를 보지 않고 판단, docs/12 D12):** 형식 파일럿(무작위 200문장)에서 ① 무효 응답률 ≤ 5%, ② 변형 3개 사이 영역 비중(해당 없음/경제/사회)의 최대–최소 차이 ≤ 0.30, ③ 변형 쌍별 영역 일치율 평균 ≥ 0.60을 모두 만족한 모델만 확증 분석에 들어간다. 탈락 모델과 파일럿 수치는 부록에 보고한다. **적용 결과 (2026-09-14, 순서 무작위화 후 파일럿):** Qwen2.5-7B · Granite-3.3-8B · Mistral-7B 적격, OLMo-2-7B 탈락(변동 0.34, 일치율 0.64). 예비 모델 **Phi-3.5-mini 적격**(변동 0.16, 일치율 0.71) → OLMo 대체. **확증 모델 4개(4개 계열): Qwen2.5-7B · Mistral-7B-v0.3 · Granite-3.3-8B · Phi-3.5-mini**, revision은 `v3/run_uk.py`의 MODELS에 전체 해시로 고정. OLMo는 기술 통계로만 보고. 임계값은 첫 파일럿을 본 뒤 정했다(docs/12 D15에 공개).

## 4. 판정 (모델 × 영역 × 집단 셀)
1. `v3.decide`: 선언문 군집 bootstrap(집단 내) B = 500, 모수적 귀무 S = 500.
2. 셀 분류: **비동등** = 95% CI가 0을 제외하고, |추정치| ≥ SESOI이고, 해당 계열(1차 `delta_pp` / 2차 `sens_diff`·`fpr_diff`)의 모수적 귀무 max-T p < .05. **동등** = 90% CI가 ±SESOI 안. 그 외는 **판정 불가**.
3. **모델 수준 결론:** 같은 집단·같은 부호의 비동등이 프롬프트 변형 3개 중 2개 이상에서 나오면 "비동등". 모든 변형에서 동등이면 "동등". 나머지는 "판정 불가".
3b. **인간 범위 비교 기준:** 각 셀에 대해 LLM 추정치가 인간 코더 leave-one-out 추정치의 [최소, 최대] 범위 밖인지 기록한다(`results/v3_calibration/{area}_human_leave_one_out.csv`; 경제 영역 인간 범위 −5.0 ~ +5.5pp). **"인간 코더보다 더 비동등하다"는 주장은 모델 수준 비동등 결론이면서 동시에 같은 부호로 변형 2개 이상이 인간 범위 밖일 때만 한다.**
4. **연구 수준 결론:** 서로 다른 계열의 모델 2개 이상이 같은 집단·부호에서 "비동등"이면 **H1 지지**. 판정 불가는 결론이 아니다. 새 사전등록 없이 확대 해석하지 않는다.
5. UK 규모의 검정력 한계(docs/12 D5, D11: 95% CI 폭 5–10pp, 약 5pp 이상만 판별)를 결과와 함께 보고한다. **UK의 "동등성 없음"은 동등성의 증거가 아니다.**
6. **추론의 알려진 한계:** 인간 leave-one-out에서 CI가 0을 포함하는데도 계열 p = 0.00인 셀이 많았다(D17). 실제 자료의 문항 이질성 때문에 모수적 귀무가 분산을 과소추정한다. 따라서 비동등 판정은 bootstrap 95% CI 조건을 반드시 함께 요구하고, 계열 p 단독으로는 어떤 주장도 하지 않는다.
7. **탐지 한계 (D19):** 사회 영역은 유병률이 낮아 민감도 0.20 차이도 집단 평균 비중으로는 약 2.6pp다. 따라서 추정량 수준의 "동등" 판정은 **오류율이 같다는 뜻이 아니며**, 사회 영역에서는 2차 통계량(`sens_diff`, `fpr_diff`)의 판정을 1차와 나란히 보고한다. 1차 결론 규칙은 바꾸지 않는다.
8. **알려진 모형 한계:** 전문가 간 문턱 차이가 커서(D10) 조건부 독립 잠재계층 가정이 근사에 불과하다. 연속 잠재척도(순서형 IRT) 모형을 민감도 분석으로 함께 보고한다.

## 5. 인간 기준선 보고
- 모든 인간 코더를 표적으로 한 같은 판정(`human_leave_one_out`)을 LLM 결과 옆에 싣는다.
- 인간 전문가도 "비동등"으로 판정된다면, 그 크기를 LLM 결과 해석의 하한 기준으로 쓴다.

## 6. 금지와 일탈 기록
- LOCK 뒤 확증 선거의 LLM 라벨을 보기 전에는 판정 규칙·SESOI·프롬프트·모델을 바꾸지 않는다.
- 일탈은 ADR로 기록하고, 일탈 전 결과도 함께 보고한다.
