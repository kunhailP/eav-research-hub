> 작성 2026-09-14 12:05 UTC. **PImPo 1차 결과(`prereg-v3-pimpo`)와 PImPo 감사 예측 결과를 보기 전**에 작성하고 커밋한다. 이후 결과를 보고 이 문서의 정의·표·AJPS 조건을 바꾸면 docs/12 §D에 일탈로 기록하고 바꾸기 전 판정도 함께 보고한다.

## 1. 결과 전에 고정하는 정의

| 용어 | 정의 |
|---|---|
| **검증을 통과한 모델** | 같은 텍스트 인간 기준에서 과제의 **합산 균형정확도(BA) ≥ 0.80**이고, 해당 연구의 형식 적격 규칙(무효 ≤ 5%, 변형 간 변동 ≤ 0.30, 변형 간 일치 ≥ 0.60)을 통과한 모델. BA는 전체 인간 기준(UK: 전문가 다수결, PImPo: 크라우드 다수결)으로 계산한다. 연구자가 보통 보고하는 합산 검증을 통과한다는 뜻이다 |
| **비교 왜곡 (모델 수준)** | 각 사전등록의 모델 수준 "비동등" 결론 (UK docs/13 §4, PImPo docs/14) |
| **비교 왜곡 (연구 수준)** | 서로 다른 계열 모델 2개 이상이 같은 집단·같은 부호로 비동등 (각 사전등록의 H1) |
| **동등성 확립** | 모델 수준 "동등"(모든 프롬프트 변형에서 90% CI가 ±SESOI 안). 판정 불가는 동등이 아니다 |
| **평판 경로 확인** | 사전등록 G(예정)의 정당명 바꿈 효과가 사전 지정 검정을 통과하고, 그 효과가 집단 비교 왜곡의 방향과 일치 |
| **크기 전환 확인** | 사전등록 G(예정)에서 같은 계열의 크기가 커질 때 \|왜곡\|의 사전 지정 추세 검정 통과 (감소 또는 비단조) |
| **감사 선별 작동** | 사전등록 F′(예정)의 판단 보류 선별 규칙이 사전 지정 기준 통과 |

## 3. 지도
프런티어 결과(X)가 1차 결정 요소다. PImPo(P)는 UK 결과의 일반성, 기제(M)와 감사(A)는 주장의 깊이를 정한다.

| X: 프런티어 같은 텍스트 | P: PImPo 오픈 모델 | 논문의 답 | 헤드라인 (확립될 때만) | 투고처 |
|---|---|---|---|---|
| **검증 통과 모델 2계열 이상 비동등** | 비동등 | **아니오 (조건 없이 위험)** | 합산 검증을 통과한 현재 모델도 급진우파·정당 비교를 인간 코더 범위 밖으로 왜곡한다 | **AJPS** (M에서 평판 경로가 확인되면 더 강함) |
| 검증 통과 모델 2계열 이상 비동등 | 동등 또는 판정 불가 | 아니오, 과제에 따라 | 검증 통과 모델도 일부 비교를 왜곡하며, 어떤 비교인지는 과제에 달렸다 | AJPS 시도 → PA |
| **검증 통과 모델 2계열 이상 동등** | 비동등 | **조건부 (정확도가 기준을 넘으면 안전)** | 약한 모델은 비교를 왜곡하지만, 검증 수준을 넘은 모델에서는 비교 동등성이 성립한다 | M에서 크기 전환이 확인되면 **AJPS 시도**, 아니면 PA |
| 검증 통과 모델 2계열 이상 동등 | 동등 | 예 (같은 텍스트 기준에서 안전) | 같은 텍스트 기준에서 LLM 비교 측정의 동등성을 처음 확립 | PA·PSRM (AJPS는 인간 코딩이 없는 언어로의 확장 근거를 보일 때만) |
| 판정 불가 또는 계열마다 엇갈림 | 무관 | 아직 답할 수 없음 | — | **투고하지 않는다.** 검정력(모델·문장 수)을 늘리는 사전등록을 먼저 한다 |

### 수정 요인
- **M 평판 경로 확인:** "왜"에 답한다. 위 표의 AJPS 행 가능성을 높인다. 경로가 없으면 기제 주장을 하지 않는다.
- **A 감사 선별 작동:** 권고 절(§6 "연구자가 할 일")의 도구가 된다. 작동하지 않으면 권고는 "비교 수준 동등성 검정" 자체로 한정하고, "300문장으로 안전한 모델을 고른다"는 쓰지 않는다.
- **E3 (Benoit 재분석)**은 모든 행에서 "문서 수준·전문가 기준에서는 불일치 증거 없음"으로만 쓴다. 환경 생태 − 사민 +0.48 경계선은 어떤 행에서도 헤드라인이 아니다.

## 4. AJPS로 가는 최소 조건 (모두 필요)
1. X에서 **검증을 통과한 현재 모델**에 대한 확립된 결론(비동등 또는 동등)이 있다. 판정 불가만으로는 가지 않는다.
2. 그 결론이 **정치학 비교**(급진우파 vs 주류, 정당 간)에 대해 인간 코더 범위와 SESOI 기준으로 실질적 크기를 가진다.
3. "왜"에 대한 답(M)이 있거나, 조건 규명 행이라면 크기·정확도 전환의 증거가 있다.
4. 모든 결과가 사전등록·잠금 순서를 지켰고, 일탈 기록으로 설명된다.

## 5. 하지 않을 것
- 결과를 본 뒤 대비·집단·SESOI를 추가하거나 바꿔 헤드라인을 만들지 않는다.
- 판정 불가를 "안전하다"로 쓰지 않는다.
- 감사 기반 **모델 선택**을 권고 헤드라인으로 쓰지 않는다(UK 탐색 E4, winner's curse).
- 인간 일치율이 낮은 소형 모델의 왜곡(E1)을 "LLM 일반"의 결론으로 쓰지 않는다.
