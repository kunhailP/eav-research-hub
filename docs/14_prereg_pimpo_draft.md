# 14 · PImPo 사전등록 초안 — 급진우파를 포함한 14개국에서 LLM 코더의 정당가족 동등성

> 상태: **LOCKED** (`docs/decisions/LOCKS.md`의 `prereg-v3-pimpo`). UK 사전등록(`prereg-v3-uk`)과 **별개**다. 이하 본문은 LOCK 시점 그대로다.
> LOCK 조건: (1) 가중 설계를 포함한 모의 귀무에서 거짓 비동등 ≤ 5% — **충족**(보정판 0/15, docs/12 D25), (2) 형식 파일럿(인간 코드 비교 없음)으로 모델 적격성 판정 — **충족**(D27), (3) 미정 항목 확정 — **충족**(SESOI 1pp, 판정 통계, 표본 설계, 확증 모델).
> **알고 설계한 것(공개 의무):** 크라우드 선택 × CMP 601/602/607/608 전체 교차표(정당가족별 분해 없음), 표 수 복원 분포, 정당가족별 문항 수, 크라우드 잠재모형의 정당가족별 유병률·오류율(보정 단계), 형식 파일럿의 LLM 응답 분포(인간 코드 비교 없음). **UK 확증 결과는 LOCK 시점에 아직 없다**(분석 실행 중).

## 1. 질문
LLM 코더가 PImPo 크라우드와 **같은 문장, 같은 질문**(이민·이민자 통합 관련 여부, 예/아니오/어쩌면)에 답할 때, **급진우파 선언문과 주류 정당 선언문에서 오류가 다른가**, 그 차이가 정당가족의 **이민 주목도(해당 문장 비중)** 비교를 몇 pp 왜곡하는가.

## 2. 자료
- PImPo 선택 단계, 비금표준 문항 **232,397개 · 선언문 241개** · 14개국 · 1998–2013 (미국 공화당 2008은 중복 결함으로 제외).
- 인간 평정자: 크라우드 3표. "예" 표 수는 집계 라벨과 최빈 응답 수로 복원한다(D20). 모호한 11,300여 문항은 **1차 = 1표, 민감도 = 0표**.
- 정당가족: 공식 MPDS2024a(API). 급진우파(70) 문항 15,152개.
- 금표준 748문항(코더 최대 203명)은 별도 검증용이다.

## 3. 추정량과 집단
- **1차 대비:** 민족주의/급진우파(parfam 70) vs 주류 합계(30 사민 · 40 자유 · 50 기민 · 60 보수, 기준 집단).
- **1차 추정량:** `delta_pp`(docs/13과 같은 정의). 크라우드만으로 정의한 잠재계층 기준으로, LLM의 급진우파 평균 해당 문장 비중 왜곡에서 불변 오류율이 만들 왜곡을 뺀 값(pp).
- **2차:** 민감도·위양성률 차이(계열 보정), 언어 집단(영어 vs 비영어 원문) 대비, 기타 정당가족은 기술 통계.
- **SESOI: 1.0pp**(확정). 잠재 유병률이 주류 3.7%, 급진우파 7.2%이므로(크라우드 잠재모형) UK의 3pp는 너무 크다. 1pp는 급진우파 유병률의 약 14%에 해당한다.
- **판정 통계:** 모수적 편향 보정판(`v3_weighted.decide_centred`). 크라우드 3표라는 약한 기준 때문에, 불변 LLM도 급진우파에서 +0.55pp로 보이는 기준 오류가 생긴다(D23). 모수적 귀무의 평균을 빼 보정한다. **잔여 편향 +0.23pp**(D25)를 공개하고, 표적을 잠재모형에 포함한 변형을 민감도 분석으로 함께 보고한다.
- **운영 특성(크라우드 표만으로 한 모의, 15회):** 귀무 거짓 비동등 0/15, 동등 12/15. 급진우파 민감도 −0.20일 때 비동등 11/15.

## 4. LLM 코딩 표본 설계 (비용)
- 전체 코딩(232,397 × 모델 4 × 변형 3 ≈ 280만 건, 약 32시간)은 과하다.
- **표본:** 크라우드 "예"가 1표 이상인 문항 **전부** + 나머지 문항의 **선언문별 층화 무작위 10%**. 포함확률 역수로 가중한다(`src/eav/v3_weighted.py`). 전체 14개국·모든 정당가족 기준으로는 약 41,000문항이지만, 1차 대비(주류 + 급진우파, 선언문 152개)만 코딩하므로 실제 코딩 문항은 아래와 같다.
- **민감도 분석 (표적 포함 잠재모형):** `v3_weighted.decide_joint`. 표본 포함 여부가 관측된 크라우드 표에만 의존하므로(MAR), 표적을 평정자로 넣은 결합 가능도는 가중치 없이 타당하다. D23의 기준 오류는 사라지지만 표적이 기준을 함께 정의하게 되므로 1차(보정판) 옆에 보고만 한다.
- 부트스트랩과 모수적 귀무는 같은 설계를 다시 뽑는다.
- 실제 규모(1차 대비 표본, 주류+급진우파만): 코딩 문항 **약 25,400개**. 적격 모델 4개 × 변형 3개 ≈ 30만 건, 약 4–5시간(RTX 3090, UK 실측 처리량 기준).
- **주의:** 표본 설계가 크라우드 표에 의존하므로, 크라우드가 모두 "아니오"인데 LLM만 "예"라고 한 문항은 10%만 관측한다 → 위양성률 추정의 분산이 크다. 모의 귀무에서 이 영향을 확인한다.

## 5. 측정도구
- **과제:** 크라우드 1라운드 지시문 원문(부록 C)의 정의·예시·세 응답, 앞뒤 2문장 맥락, 문장별 선택지 순서 무작위화. 응답 매핑은 크라우드와 같게 예=1, 어쩌면=0.5, 아니오=0이다. 잠재모형 입력은 예=1, 나머지=0으로 하고, 어쩌면=1은 민감도 분석으로 돌린다.
- **프롬프트 변형:** `label/tasks/v3_pimpo/selection_{a,b,c}.json`.
- **모델:** 원문이 다국어(독일어·스페인어·영어·노르웨이어·네덜란드어·핀란드어·스웨덴어·덴마크어 등)라서 적격성 파일럿을 PImPo 문장으로 새로 했다(UK 적격성을 그대로 쓰지 않음, D27). 규칙은 UK와 같다(무효 ≤ 5%, 변동 ≤ 0.30, 일치율 ≥ 0.60).
  **확증 모델 4개(4개 계열): Qwen2.5-7B · OLMo-2-7B · Granite-3.3-8B · Phi-3.5-mini**. revision은 `v3/run_pimpo.py`의 CANDIDATES/ELIGIBLE에 전체 해시로 고정한다. Mistral-7B는 탈락(변동 0.32).
  **"어쩌면" 매핑:** Phi는 파일럿에서 "어쩌면" 응답이 29–50%였다. 1차(어쩌면 = 아니오)와 민감도(어쩌면 = 예, `--possibly-as-yes`)를 **모델별로 모두** 보고한다.
  **오염 점검:** OLMo-2의 학습 데이터(Dolma)가 공개돼 있으므로, PImPo 원문의 학습 데이터 포함 여부 점검을 부록으로 보고한다.

## 6. 판정
- 셀 분류와 모델·연구 수준 결론 규칙은 docs/13 §4와 같다(SESOI만 §3의 값).
- **인간 기준선:** 코더 id가 없어 인간 leave-one-out은 불가능하다. 대신 금표준 문항에서 크라우드 단일 표의 정당가족별 오류를 기술 통계로 보고한다.

## 7. 알려진 한계
- 크라우드 3표 이항 잠재모형은 집단별로 겨우 식별된다. 코더 품질이 문항 난이도와 섞일 수 있다.
- 크라우드 지시문은 독일어·스페인어로만 번역됐고, 나머지 언어는 국가·언어 요건으로 대신했다 → 크라우드 자체의 언어별 비동등 가능성.
- 1998–2013 자료라 모든 후보 모델의 학습 cutoff 이전이다(오염 가능).
- 중동유럽이 없다. 동서 비교는 이 사전등록의 범위 밖이다.
