# 21 · 사전등록 G 설계 메모 — 모델 크기 × 정당 단서 (사전등록 전)

> 상태: **설계 메모. 사전등록 아님.** 결정된 것과 사전등록 전에 정할 것을 나눈다. 사전등록 G는 이 메모를 바탕으로 작성하고, LLM 출력을 인간 기준과 비교하기 전에 잠근다.
> 연결: 고정 질문(LLM으로 잰 정당들을 비교해도 되는가), 결과 → 결론 지도 docs/19의 "평판 경로 확인"·"크기 전환 확인", 원장 E7·E8.

## 1. 기제 질문
모델이 커지면 텍스트 이해가 좋아져 무작위 오류가 줄지만, 정당에 대한 사전 지식(평판)도 늘어난다. 평판이 판단에 섞이면 **집단별 체계적 오류는 줄지 않거나 오히려 커질 수 있다.** 크기 사다리만으로는 두 경로를 가를 수 없으므로(둘 다 크기와 함께 변함), 정당 정보를 **무작위로 조작**해 평판 경로를 직접 식별한다.

## 2. 결정된 것
| 항목 | 결정 | 이유 |
|---|---|---|
| 조작 | 프롬프트 앞 정당 단서 3조건: **없음**(현행) · **실제 정당** · **바꾼 정당** | 라벨러가 `--cue-template`을 이미 지원한다(잠긴 코드 수정 불필요). 문서 단위로 정당을 알고 코딩하는 실무(Benoit et al. 2026의 선언문 요약 채점 등)를 반영한다 |
| 1차 과제 | **UK 11개 선택지(영역 × 좌우 위치)** | 평판은 주제 선택보다 **위치 판단**에 크게 작용할 것으로 예상된다. 영어 단일 언어라 언어 교란이 없다. 인간 다평정자 기준이 풍부하다 |
| 바꾼 정당 | 보수 ↔ 노동, 자민 → 보수 (사전등록에서 확정) | 좌우 평판 차이가 가장 큰 쌍 |
| 1차 추정량 | **같은 문장 안의 단서 효과:** 바꾼 단서 − 실제 단서 조건의 위치 점수 차이와 영역 배정 변화율 (문장 내 짝 비교) | 인간 기준 없이 잴 수 있고, 짝 비교라 정밀하다 |
| 2차 추정량 | 단서 조건별 v3 `delta_pp` (인간 잠재계층 기준) | 단서가 **정당 비교 왜곡**을 실제로 키우는지 연결 |
| 크기 사다리 | Qwen2.5-Instruct 0.5·1.5·3·7·14B(AWQ), OLMo-2-Instruct 1·7·13B(양자화), Granite-3.3 2·8B | 접근 제한 없음, 계열 3개. Qwen3은 생각 모드를 끌 수 없어 제외(D43). Llama·Gemma는 접근 동의 필요 |
| 보조 과제 | PImPo 이민 선택, 같은 3조건(바꾼 정당 = 같은 나라의 반대 진영) | 다국어·급진우파로의 일반화 |

## 3. 사전등록 전에 정할 것
1. **문장 부분표본 크기와 추출:** 계산량(모델 10개 × 조건 3 × 문장 수)을 GPU 시간에 맞춘다. 후보는 정당별 1,000문장(총 3,000, 짝 비교 검정력을 모의로 계산해 결정)
2. **프롬프트 변형:** 비용 때문에 변형 a 하나로 할지, 3개를 유지할지 (UK 사전등록은 변형 3개가 재현 조건)
3. **모델별 형식 적격:** UK와 같은 규칙(무효 ≤ 5%, 변동 ≤ 0.30, 일치 ≥ 0.60)을 소형 모델에도 적용하면 0.5–1.5B가 탈락할 수 있다 → 탈락 모델 보고 방식
4. **크기 추세 검정:** log(파라미터 수)에 대한 단서 효과의 기울기(계열 고정효과) + 비단조성 검정(2차항). 계열당 크기 2–5단계라 검정력이 약하다 → 모의 보정 필요
5. **양자화 교란:** 14B(AWQ)와 13B(양자화)는 원본과 다르다 → 7B·8B 원본 대비 양자화 효과 보조 점검
6. **"평판 경로 확인" 판정 규칙:** 단서 효과가 SESOI 이상 + 방향이 평판과 일치(보수 단서 → 오른쪽 이동) + 그 효과가 `delta_pp` 왜곡 방향과 일치
7. **문장 속 정당명 가림(보조):** 현지어 정당명·약칭 사전을 만든 뒤 빈도를 다시 센다(D43에서 영어 번역명 집계 철회)

## 4. 일정과 순서
1. PImPo 라벨링 종료 후 GPU 확보
2. 사다리 모델 형식 파일럿 (인간 코드 비교 없음, UK·PImPo 파일럿과 같은 방식)
3. 짝 비교 검정력 모의 → §3 결정 → 사전등록 G 작성·잠금
